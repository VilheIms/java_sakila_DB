# [h1] Java sakila database viewer

This project has been created to view the "sakila" database using the eclipse terminal.

Using this tool, you are able to INSERT, UPDATE, DELETE and VIEW table data, selecting from (currently) 4 different tables.

Information is printed out with colour, changing colour between rows.

## Current tasks:
- [x] Able to view table
- [x] Able to limit table view
- [x] Able to delete from database
- [x] Able to insert into database
- [x] Colour changes between rows
